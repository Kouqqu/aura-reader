Aura Reader — открытый и прозрачный ридер электронных книг для Android

Кратко о главном:

В приложении нет учетных записей, рекламных баннеров и рекламных трекеров. Ваши книги, прогресс чтения, закладки и настройки хранятся строго локально на вашем смартфоне.

1. Данные, которые остаются на вашем устройстве

В защищенном хранилище приложения сохраняются и никогда не загружаются в сеть:

  • Импортированные файлы книг (EPUB, FB2, TXT, PDF, CBZ/CBR), извлеченные тексты и обложки;
  • Прогресс чтения, закладки, цитаты, личные коллекции и статистика;
  • Все локальные параметры оформления (шрифты, тема интерфейса, скорость TTS-озвучки);
  • Адреса и логины добавленных вами OPDS-каталогов;
  • Индекс локальной библиотеки.

2. Анонимная агрегированная статистика

Aura Reader использует европейский сервис TelemetryDeck исключительно для подсчета активных пользователей приложения. Вы можете полностью отключить сбор данных в Настройки → Анонимная статистика в один клик.

Событие Когда отправляется Что содержит
app_open При открытии ридера Код страны сети, язык системы, канал сборки (beta/stable)
app_first_open Один раз при установке Случайный локальный ID установки (без привязки к аккаунту Google)
app_update После обновления версии Предыдущий номер сборки для анализа успешности апдейта

3. Внешние сервисы по запросу пользователя

Обращение к сторонним серверам происходит только тогда, когда вы сами запускаете соответствующее действие:

  • Поиск обложек (LitRes, FantLab, OpenLibrary, Apple Books) — отправляется только введенное вами название книги или автор;
  • OPDS-каталоги — сетевой запрос отправляется напрямую на сервер каталога, который вы указали;
  • Проверка обновлений — прямой защищенный запрос к открытому GitHub API репозитория.

4. Исходный код и аудит

Aura Reader полностью открыт. Любой разработчик или энтузиаст может проверить исходный код приложения и убедиться в отсутствии недокументированных сетевых активностей в официальном репозитории на GitHub.
