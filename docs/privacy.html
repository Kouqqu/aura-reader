Политика конфиденциальности

Aura Reader — открытый проект без рекламы и скрытого сбора данных

Ключевой принцип:

В приложении нет аккаунтов, профилирования и рекламных трекеров. Все книги, цитаты, настройки и прогресс чтения хранятся исключительно локально на вашем смартфоне.

1. Данные на вашем устройстве

В изолированном хранилище приложения сохраняются и никогда не передаются во внешнюю сеть:

  • Файлы книг (EPUB, FB2, PDF, TXT, CBZ, CBR) и обложки;
  • Прогресс чтения, закладки, цитаты, коллекции и статистика времени чтения;
  • Пользовательские настройки типографики, темы и скорости TTS-озвучки;
  • Адреса добавленных вами каталогов OPDS;
  • Локальный индекс библиотеки.

2. Анонимная статистика (отключаемая)

Aura Reader может отправлять базовую статистику через независимый сервис TelemetryDeck (серверы в Германии, ЕС) исключительно для подсчёта активных установок и анализа стабильности версий. Это можно отключить в любой момент в Настройки → Анонимная статистика.

Событие Условие Передаваемые данные
app_open Запуск приложения Код страны сети, язык системы, канал сборки (beta/stable)
app_first_open Первый запуск после установки Случайный локальный идентификатор установки
app_update После установки новой версии Предыдущий код сборки

3. Внешние сервисы по прямому запросу

Сетевые обращения осуществляются только при явном действии пользователя:

  • Поиск обложек (LitRes, FantLab, OpenLibrary) — отправляется только поисковая строка (название книги или автор);
  • Каталоги OPDS — прямой запрос на сервер указанной вами электронной библиотеки;
  • Проверка обновлений — прямой запрос к открытому GitHub API репозитория.

4. Открытый исходный код

Исходный код приложения опубликован под лицензией GPL-3.0. Вы можете лично изучить архитектуру и сетевые вызовы в официальном репозитории на GitHub.
